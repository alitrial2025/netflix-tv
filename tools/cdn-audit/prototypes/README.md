# Preserved local research

`NetflixSeasonResolver.kt` is an unused experimental resolver from the earlier local investigation. It is preserved here outside Android's production source sets. The released apps use `PublicPlaybackResolver` and `ProviderEpisodeCatalog` instead.

The sibling exploratory scripts, HTML snapshots, reports and `ZERO_COOKIE_OTT_GUIDE.md` record historical experiments. Their endpoint availability, timing estimates and conclusions are not current guarantees. Expired session values in snapshots are redacted. These scripts are not run by the release workflow.
