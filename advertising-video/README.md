## Re-render on Windows

Requirements: Python, Pillow, NumPy, FFmpeg, and the Windows Arial/Segoe UI fonts.

Set `AD_FFMPEG` to your FFmpeg executable if it is not at the path specified at the top of the script. From this folder, run:

```powershell
$env:AD_FFMPEG = 'C:\tools\ffmpeg.exe'
python .\render_video.py
```

For just the cover and storyboard:

```powershell
python .\render_video.py --storyboard-only
```

The export always uses one renderer and one encoder thread at Windows idle priority. It paces the combined CPU time to 35% of one logical core, pauses for six seconds every 25 seconds, and takes ten-second breaks between chapters. Picture quality, duration, and playback frame rate stay at the values above; export takes longer.

Only one worker is permitted. Completed chapters are checked for the correct duration and frame count before reuse. Frames are streamed to the encoder, and image caches are released between chapters to keep memory use down. An interrupted chapter is rendered again; completed chapters survive a restart.

After editing a chapter, remove only that chapter’s file from `.render-cache` before rendering again. The CPU budget reduces rendering load; it does not read the hardware’s temperature sensors.

## What the film represents

This is a code-rendered interface demonstration, based on the current Kotlin app layouts and interactions. It is not a recording of a running APK, and it does not measure app startup, memory use, playback quality, or device performance. No Android build was run.

Artwork, episode images, subtitle text, viewing history, and track choices are illustrative. The depicted search filters, saved state, and selected language are staged consistently. Availability in the app depends on the catalogue and stream.

The brand paths come from the app’s existing drawable resources. Movie/series artwork is from the source URLs in `asset-sources.json`. Music and navigation sounds are generated by the included code. There is no film dialogue or third-party music in this video. Netflix Pro is an independent app; the film does not claim affiliation with Netflix.
