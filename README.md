# Netflix Pro for Android TV

Kotlin and Jetpack Compose Android TV project. Application code and bundled assets are in app/src; Gradle configuration and wrappers are at the project root.

Open this folder in Android Studio when preparing your own build. Runtime configuration uses the existing Gradle/BuildConfig and Firebase configuration.

Supporting material is in docs, marketing-site, and advertising-video. The Android app does not require Node or Python. Loose test/fixing scripts and obsolete duplicate resolvers were archived during workspace cleanup on 2026-09-29.
