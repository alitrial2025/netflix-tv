Install on Your Device

Four simple steps. No technical knowledge required.

1

Download the APK

Click the button below. Choose TV or phone in Downloads. Each release shows its version and file size.

2

Transfer to your TV

Sideload via USB, ADB, or a cloud drive. Or download directly on your TV's browser.

3

Review Android’s install prompt

These APKs are installed outside Google Play. Review the developer, build type and requested permissions. Keep Play Protect enabled; do not bypass a security warning.

4

Install and launch

Install only if you trust this independent project. Browse previews as a guest or create a separate NetflixPro account. Never enter your Netflix password.

About this independent project

NetflixPro is an independent Android app project maintained by mzazimhenga. It is not Netflix, Inc. and is not affiliated with, endorsed by, or sponsored by Netflix or any streaming service.

Website privacy

This marketing page does not ask for passwords, payment details, or Netflix account information. The interactive tours use temporary demo state in your browser and do not sign you into an account. This page has no advertising or analytics scripts. Vercel hosts this website and its APK downloads; TMDB receives requests for illustrative artwork.

App downloads and plans

APK downloads are provided by this project, outside Google Play. Review each build’s version and build type before choosing to download. Keep browser and Android security protections enabled.

Downloading the app is free. Guest access offers browsing and trailers. Full playback requires a NetflixPro plan selected in the phone app; its price and device limit are shown before payment. A NetflixPro plan is separate from subscriptions to other streaming services. Content availability varies.
